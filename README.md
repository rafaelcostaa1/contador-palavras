# Contador de Palavras em Python

Projeto simples desenvolvido em Python para contagem de palavras em textos, utilizando manipulação de strings.

## Funcionalidades

- Contar a quantidade de palavras em um texto
- Processar entrada de dados pelo usuário
- Exibir o resultado da contagem no terminal

## Tecnologias

- Python

## Como executar

Clone o repositório:
git clone https://github.com/rafaelcostaa1/contador-palavras

Acesse a pasta do projeto:
cd contador-palavras

Execute o programa:
python main.py

## Observação

O programa realiza a contagem de palavras com base no texto informado pelo usuário durante a execução.
